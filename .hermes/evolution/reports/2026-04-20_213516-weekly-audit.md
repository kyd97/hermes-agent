But `run_agent.py:6778` passes only `messages` into `context_compressor.compress(...)`, and `agent/context_compressor.py:344-458` builds the summary prompt from serialized turns only, so provider hints do not materially shape the generated summary.

## Highest-leverage next implementation
**A2 — Wire `on_turn_start` memory hooks into the main loop.**

Why this is the best next P0/P1 item:
1. It is **P0** and already has most of the plumbing: the hook exists in `agent/memory_provider.py:144-151` and is dispatched by `agent/memory_manager.py:260-272`.
2. The main loop gap is narrow and clear: `run_agent.py:8020-8030` currently prefetches memory but never calls `on_turn_start(...)`.
3. Wiring it now unlocks cadence-aware capture/recall for all memory providers immediately, which increases the value of the existing memory-provider subsystem without requiring a broad schema redesign.
4. It also sets up later memory roadmap items more cleanly, especially A3-A5.
